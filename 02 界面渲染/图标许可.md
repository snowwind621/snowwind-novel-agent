# 图标许可

## 来源

- 项目：[Lucide](https://github.com/lucide-icons/lucide)（Feather 的继任者，线性风格）
- 分发包：[`lucide-static`](https://www.npmjs.com/package/lucide-static) **v1.77.0**，取的是同一版本的原始 SVG
- 取图方式：逐个 `https://unpkg.com/lucide-static@latest/icons/<name>.svg`，只截取 `<svg>` 内部的图形片段

## 我们是怎么用的

- **只内联了 path 数据**：每个图标的 `<path> / <circle> / <rect> / <line> / <polyline>` 片段被抄进 `图标.tsx` 的常量表。
- **没有引入它的运行时包**：`package.json` 里没有 `lucide` / `lucide-react` / `lucide-static`，构建产物里也没有第三方 SVG 运行时。
- **运行时零网络请求**：所有图形都是编译进包里的字符串，不 fetch、不加载图标字体、不请求 CDN。
- 统一 24×24 网格、`stroke-width: 1.75`、`currentColor`，颜色跟随主题。

## 以后要加图标

1. 取 `https://unpkg.com/lucide-static@latest/icons/<name>.svg`；
2. 只留 `<svg>` 内部的图形片段，压成一行；
3. 追加进 `图标.tsx` 的 `记录` 表，并在文件头注释的映射表里登记中文名；
4. 若换了 Lucide 大版本，更新本文件的「分发包版本」与协议原文。
