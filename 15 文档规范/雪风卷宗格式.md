# 雪风卷宗 · 书库格式 v1

本软件只认这一种格式。它是纯文本的：**离开软件也读得懂、改得动、能进 Git**。

## 一眼看懂

```
<书库根>/
  书卷.yaml                一本书的自述
  正文/
    第一卷/
      第001章 粉丝一百.md
      第002章 泳池、演练与温水.md
    第二卷/
      …
  设定/
    世界观/  人物/  地点/  物品/  势力/  制度/  事件/  规则/  备注/
    面板镜像.json          设定面板的只读镜像（含伏笔的参考间隔）
  台账/
    时间线.md
    出场追踪.md
    关系线.md
    属性变更.md
    队伍状态.md
    物品台账.md
    承诺台账.md
  情节/
    分卷大纲.md
    细纲/
  校验/  留痕/  考据/  导航/  讨论/
```

## 三条规矩

1. **一个事实只存一处。** 正文在 `正文/`，会变的数据在 `台账/`，稳定设定在 `设定/`。别处只写指针。
2. **文件名即数据。** 章号写在文件名里（`第001章`），卷号写在目录名里（`第一卷`），不需要索引文件。
3. **讨论区不作依据。** `讨论/` 放派活记录、争论、草稿，任何判定都不许引用它。

## 书卷.yaml

```yaml
格式: 雪风卷宗/1
书名: 世界末日也要涨粉
作者: 雪风
建立于: 2026-11-20
```

`格式` 是版本号。以后改格式就升这里，软件据此判断能不能读。

## 正文

- 一章一个文件：`第NNN章 标题.md`，三位对齐（`第001章`、`第027章`）。
- 卷是目录：`第一卷`、`第二卷`……中文数字，最多到「第九十九卷」。
- 正文就是正文，不加 frontmatter、不加元信息。段落用两个全角空格缩进，与纸稿一致。
- 章号必须唯一且递增；中间留空没关系（`第001章` 后面直接 `第005章` 也能读）。

## 设定

`设定/` 下按类分目录：世界观、人物、地点、物品、势力、制度、事件、规则、备注。
一份设定一个 `.md` 文件，文件名就是它的名字（`丸井三叶.md`）。

允许的 frontmatter（全部可选）：

```yaml
---
名称: 丸井三叶
别名: [三酱, 长女]
标签: [主角, 第一视角]
---
```

## 台账

七册固定，缺了就是没有，不用建空文件：

| 册 | 答什么问题 |
|---|---|
| 时间线.md | 哪天发生了什么、这一章是哪天 |
| 出场追踪.md | 谁在哪一章出现过 |
| 关系线.md | 每对关系怎么变的 |
| 属性变更.md | 数值旧→新、依据哪一句 |
| 队伍状态.md | 谁在哪、走不走 |
| 物品台账.md | 东西在谁手上、什么状态 |
| 承诺台账.md | 伏笔埋在哪、兑没兑 |

台账正文用 Markdown 表格，表头决定列含义。软件按表头找列，不按位置——所以你可以加列、调顺序。

## 面板镜像.json

`设定/面板镜像.json` 是设定的结构化镜像，目前只用到其中「伏笔」条目的参考间隔：

```json
{ "条目": [{ "编号": "p-019", "名称": "留在桌脚下的药箱", "类型": "伏笔", "参考间隔": 6 }] }
```

没有这个文件也能用，只是伏笔看板少了「超期」判定，只剩「久置」。

## 迁移旧格式

旧格式（NeuroBook 风格）的目录可以一次性转换：

```bash
node dist/导入.cjs <旧书库目录> <新书库目录>
```

或在软件里：右上角「设置」→「书库迁移」→「从旧格式导入…」。

转换规则：`manuscripts.binder` → `正文/第X卷/第NNN章`，`lorebook/<类>` → `设定/<中文类>`，
`reference/台账` 七册改名进 `台账/`，其余附录进 `情节/校验/留痕/考据/导航/讨论`。**旧目录只读不动。**
