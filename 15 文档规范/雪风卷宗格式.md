# 雪风卷宗 · 书库格式 v1

本软件只认这一种格式。它是纯文本的：**离开软件也读得懂、改得动、能进 Git**。

## 一眼看懂

```
<书库根>/
  书卷.yaml                一本书的自述
  正文/
    第一卷/
      第001章 粉丝一百.md
      第002章 泳池、演练与温水.md
    第二卷/
      …
  设定/
    世界观/  人物/  地点/  物品/  势力/  制度/  事件/  规则/  备注/
    面板镜像.json          旧格式残留，软件不读（只有迁移旧书库时读一次）
  台账/
    时间线.md
    出场追踪.md
    关系线.md
    属性变更.md
    队伍状态.md
    物品台账.md
    承诺台账.md
  情节/
    分卷大纲.md
    细纲/
    开写包/          总编合成的开写包，一章一份，可当依据
  校验/  留痕/  考据/  导航/  讨论/
```

## 三条规矩

1. **一个事实只存一处。** 正文在 `正文/`，会变的数据在 `台账/`，稳定设定在 `设定/`。别处只写指针。
2. **文件名即数据。** 章号写在文件名里（`第001章`），卷号写在目录名里（`第一卷`），不需要索引文件。
3. **讨论区不作依据。** `讨论/` 放派活记录、争论、草稿，任何判定都不许引用它。

## 书卷.yaml

```yaml
格式: 雪风卷宗/1
书名: 世界末日也要涨粉
作者: 雪风
建立于: 2026-11-20
```

`格式` 是版本号。以后改格式就升这里，软件据此判断能不能读。

## 正文

- 一章一个文件：`第NNN章 标题.md`，三位对齐（`第001章`、`第027章`）。
- 卷是目录：`第一卷`、`第二卷`……中文数字，最多到「第九十九卷」。
- 正文就是正文，不加 frontmatter、不加元信息。段落用两个全角空格缩进，与纸稿一致。
- 章号必须唯一且递增；中间留空没关系（`第001章` 后面直接 `第005章` 也能读）。

### 正文里的 Markdown

正文按 Markdown 渲染：标题 `##`、引用 `>`、无序 / 有序列表、表格、加粗 `**`、斜体 `*`、行内代码 `` ` ``、分割线 `---` 都认。编辑器有「富文本 / 源码 / 分屏 / 预览」四态，工具栏只负责替你插这些标记；富文本是所见即所得，但落盘仍然是这些标记本身。

但**小说正文仍以全角缩进段落为主**：两个全角空格开头就是普通段落，不会被当成代码块，也不会自动变成特殊缩进。预览只是渲染，磁盘上永远是纯文本 `.md`——换个编辑器照样能读、能改、能进 Git。

## 设定

`设定/` 下按类分目录：世界观、人物、地点、物品、势力、制度、事件、规则、备注。
一份设定一个 `.md` 文件，文件名就是它的名字（`丸井三叶.md`）。

允许的 frontmatter（全部可选）：

```yaml
---
名称: 丸井三叶
别名: [三酱, 长女]
标签: [主角, 第一视角]
---
```

## 台账

七册固定，缺了就是没有，不用建空文件：

| 册 | 答什么问题 |
|---|---|
| 时间线.md | 哪天发生了什么、这一章是哪天 |
| 出场追踪.md | 谁在哪一章出现过 |
| 关系线.md | 每对关系怎么变的 |
| 属性变更.md | 数值旧→新、依据哪一句 |
| 队伍状态.md | 谁在哪、走不走 |
| 物品台账.md | 东西在谁手上、什么状态 |
| 承诺台账.md | 伏笔埋在哪、兑没兑 |

台账正文用 Markdown 表格，表头决定列含义。软件按表头找列，不按位置——所以你可以加列、调顺序。

### 承诺台账的三个可选列

`承诺台账.md` 有三列可选，都可以不写（软件按表头文字找列，不按位置）：

| 列 | 取值 | 没写时 |
|---|---|---|
| `参考间隔` | 纯数字，如 `6`（写成 `6 章` 也认）——这条从埋下到兑掉大约隔几章 | 不参与「超期」判定，只按「搁置太久」（埋下 ≥ 15 章还没兑）提醒 |
| `重要程度` | 自由文字，习惯写 `main`（终局与长线）/ `side`（其余） | 按 `side` |
| `意图` | 自由文字，习惯写 `active`（在跟）/ `dropped`（已销） | 按 `active` |

三列只影响伏笔看板的显示与超期判定：**台账是唯一正本，软件不再读任何外部镜像文件**。

## 面板镜像.json（旧格式残留，软件不读）

旧版软件把设定的结构化副本放在 `设定/面板镜像.json`。**新格式不再依赖它**：伏笔的 `参考间隔` / `重要程度` / `意图` 都写在 `台账/承诺台账.md` 的列里。

只有迁移旧书库时，导入器会读一次旧镜像（旧书库的 `reference/设定面板-现状.json`），把这三项并进新台账的对应列；镜像本身不带进新书库。

新书库没有这个文件也完全正常。

## 结构契约（格式 A）

书库是 Markdown，但**结构是硬的**：`10 书库检索/书库结构.ts` 把契约写成常量，`18 构建工具/校验书库.mjs` 照它体检。

### 设定卡 frontmatter 七个字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `名称` | ✅ | 文本 | 卡片名 |
| `类型` | ✅ | 文本 | 人物 / 地点 / 物品 / 势力 / 制度 / 事件 / 规则 / 备注 / 世界观 |
| `状态` | ✅ | 文本 | 在用 / 已弃 这类自由文字 |
| `别名` | — | 字符串列表 | `[三酱, 长女]` 或 `- 三酱` 块数组 |
| `标签` | — | 字符串列表 | 自由打标 |
| `首次出场` | — | 章号 | `ch24` / `第24章` / `24` |
| `摘要` | — | 文本 | 一句话说清这张卡 |

白名单之外的字段**不报错、只报「提示」**；旧外部字段（`title` / `type` / `status` / `aliases` / `tags` / `summary`）会被认出来，提示换成中文键。

### 台账七册：必需列

列按**表头文字**找（认别名，包含即可），同一册里任意一张表凑齐就算过：

| 册 | 必需列（列类型） | 编号唯一 |
|---|---|---|
| `时间线.md` | 日期（文本）、事件（文本）、章节（章号） | — |
| `出场追踪.md` | 姓名（文本）、最后出场（文本） | — |
| `关系线.md` | 编号（文本）、关系对（文本）、章（章号） | 编号 |
| `属性变更.md` | 时点（文本）、角色（文本）、属性（文本）、旧→新（文本）；章（章号）可选 | — |
| `队伍状态.md` | 项（文本）、现值（文本） | — |
| `物品台账.md` | 物品（文本）、状态（文本） | — |
| `承诺台账.md` | 编号（文本）、承诺（文本）；埋 / 兑（文本）与参考间隔（数字）可选 | 编号 |

### 章号 / 数字 / 日期怎么算合法

- **章号**：`ch27`、`第27章`、`27`、`第3卷/027` 都认；一格写多个用 `／` `、` `,` 分隔；空、`—`、`-`、`未定` 一律算「没写」。
- **数字**：纯数字（可带小数），可带「章」后缀；空 / `—` / `-` / `未定` 算没写。
- **日期**：`2026-11-20`、`4月6日`、`第3日`、`3/15` 这类；同样空与破折号算没写。

### 校验书库

```bash
node "18 构建工具/校验书库.mjs" <书库目录>              # 人读报告；有「错误」退出码 1
node "18 构建工具/校验书库.mjs" <书库目录> --json        # 机器读
node "18 构建工具/校验书库.mjs" <书库目录> --修复建议    # 只给建议，不落盘
```

报告按类别归组，主要几类：`设定卡缺 frontmatter` / `设定卡缺字段` / `设定卡字段类型` / `设定卡未知字段`（提示）/ `台账缺册` / `台账缺表` / `台账缺列` / `台账列类型` / `编号重复` / `章号越界` / `引用断链` / `同一事实两处`。

### 只读投影：agent 怎么查事实

`06 智能体运行时/书库投影.ts` 把 Markdown 在**内存里**投影成结构化 JSON（台账 → 表 / 列 / 行，设定 → 字段 + 正文开头，伏笔 → 和看板同一套状态机），**不落盘、不建第二份文件**。

对话里的 `查台账` / `查设定` / `查伏笔` 三个工具都走它。所以永远是三层：**Markdown 正本 → 只读投影（内存） → agent**，没有第四层缓存文件可以失真。

## 迁移旧格式

旧格式（NeuroBook 风格）的目录可以一次性转换：

```bash
node 99 构建产物/导入.cjs <旧书库目录> <新书库目录>
```

或在软件里：右上角「设置」→「书库迁移」→「从旧格式导入…」。

转换规则：`manuscripts.binder` → `正文/第X卷/第NNN章`，`lorebook/<类>` → `设定/<中文类>`，
`reference/台账` 七册改名进 `台账/`，其余附录进 `情节/校验/留痕/考据/导航/讨论`。**旧目录只读不动。**
