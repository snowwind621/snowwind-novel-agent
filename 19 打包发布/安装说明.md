# 雪风小说工坊 · 安装说明（给收到安装包的人）

> 这一版**没有买代码签名证书**，所以 Windows 第一次运行会拦一下。不是病毒，按下面点两次就好。

## 装

1. 双击 `雪风小说工坊-<版本>-安装版.exe`。
2. 如果出现蓝底提示「**Windows 已保护你的电脑**」：点左侧「**更多信息**」→「**仍要运行**」。
3. 按向导走：可以改安装目录；装完开始菜单和桌面各有一个「雪风小说工坊」。
4. 装的是**当前用户**，不需要管理员密码。

## 首次启动又拦一次？

同一套动作：「更多信息 → 仍要运行」。**只在这台机器的第一次**，之后不再问。

杀毒软件若报「未签名程序 / 可疑」，把安装目录加白名单即可——程序不往任何地方上传内容，唯一的对外请求是你自己配置的模型网关。

## 卸载

设置 → 应用 → 雪风小说工坊 → 卸载，或开始菜单里的「卸载」。
**卸载不会删你的书库和设置**（`%APPDATA%\snowwind-novel-agent`）。要彻底清干净，卸载后手动删这个目录。

## 更新

程序会自己在后台检查新版本，下载完在下次退出时装上，不需要你手动下载安装包。长期离线的话，联网后启动一次即可。
